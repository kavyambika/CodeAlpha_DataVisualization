# CodeAlpha Data Visualization Project

## About the Project
This project focuses on analyzing and visualizing chocolate sales shipment data using Python. It was completed as part of my CodeAlpha Data Analytics Internship.

## Dataset
- Dataset: Chocolate Sales Dataset
- Total Records: 7,905
- Tools: Google Colab

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations Created
1. Shipment Count by Order Status
2. Monthly Shipment Amount Trend
3. Top 10 Products by Recorded Amount
4. Order Status Distribution
5. Monthly Shipment Amount Heatmap

## Key Learning Outcomes
- Data visualization using Python
- Data grouping and aggregation
- Identifying patterns and trends
- Creating meaningful charts from datasets

## Project Files
- `CodeAlpha_DataVisualization.ipynb` – Jupyter Notebook containing the analysis and visualizations.
- `CodeAlpha_DataVisualization_Charts.zip` – ZIP file containing the generated charts.
